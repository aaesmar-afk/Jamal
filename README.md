# تطبيق سوبر ماركت الجمال (APK عبر GitHub Actions)

هذا المجلد جاهز ليتحول تلقائيًا إلى تطبيق أندرويد (APK) بدون تثبيت Android Studio على جهازك — البناء يتم على سيرفرات GitHub مجانًا.

## الخطوات

### 1) أنشئ مستودع (Repository) جديد على GitHub
اذهب إلى https://github.com/new وأنشئ مستودعًا جديدًا (يفضّل private إذا كان النظام يحتوي بيانات حساسة).

### 2) ارفع هذه الملفات إلى المستودع
من جهازك (بعد فك ضغط الملف الذي حصلت عليه):

```bash
cd supermarket-app
git init
git add .
git commit -m "إعداد أولي للتطبيق"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
(استبدل USERNAME و REPO_NAME باسمك واسم المستودع)

### 3) شغّل البناء
بمجرد الرفع (push)، سيبدأ GitHub Actions تلقائيًا ببناء ملف APK. لمتابعة التقدم:
- افتح صفحة المستودع على GitHub
- اضغط تبويب **Actions**
- ستجد عملية "Build APK" قيد التشغيل (تأخذ عادة 3-6 دقائق)

### 4) تحميل ملف APK
بعد اكتمال البناء بنجاح (علامة ✅ خضراء):
- افتح الـ workflow run
- في الأسفل ستجد قسم **Artifacts**
- حمّل الملف المسمى `app-debug-apk`
- فك الضغط عنه، ستجد بداخله `app-debug.apk` — انقله لهاتف أندرويد وثبّته (قد تحتاج للسماح بـ"التثبيت من مصادر غير معروفة" في إعدادات الهاتف)

## ملاحظات مهمة

- **هذا إصدار Debug** (للتجربة). لإصدار نهائي (Release) موقّع لنشره على متجر Google Play، تحتاج خطوة إضافية لإنشاء مفتاح توقيع (keystore) — أخبرني إذا احتجت ذلك لاحقًا.
- **أيقونة التطبيق والشاشة الافتتاحية (Splash)**: افتراضيًا ستكون أيقونة Capacitor العامة. يمكن تخصيصها لاحقًا.
- **اتصال الإنترنت**: التطبيق يستخدم Supabase، لذا سيحتاج الهاتف لاتصال بالإنترنت ليعمل بشكل صحيح.
- إذا عدّلت ملف `www/index.html` لاحقًا وعملت push جديد، سيُعاد بناء APK تلقائيًا بأحدث نسخة.

## هيكل المشروع
```
supermarket-app/

├── package.json

```
